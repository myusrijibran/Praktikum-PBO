Minpro-1-PBO-ManajemenRentalPS
Deskripsi Singkat Program
Program Manajemen Rental PS merupakan aplikasi berbasis Java yang digunakan untuk membantu proses pengelolaan rental PlayStation. Program ini memiliki beberapa fitur untuk mengelola data rental serta melakukan proses penyewaan PS.

Program ini dibuat menggunakan bahasa Java dengan menerapkan konsep Pemrograman Berorientasi Objek (PBO).

Penjelasan Alur Program
Alur program dimulai dengan menampilkan menu utama kepada pengguna. Pengguna dapat memilih menu sesuai dengan kebutuhan.

Program menampilkan menu utama.
Pengguna memilih menu yang tersedia.
Pengguna dapat melihat data rental PS.
Pengguna dapat menambahkan data rental.
Pengguna dapat mengubah data rental.
Pengguna dapat menghapus data rental.
Pengguna dapat melakukan proses rental PS.
Program menampilkan hasil dari proses yang dipilih.
Pengguna dapat kembali ke menu utama atau keluar dari program.
Secara sederhana, alur program adalah:

Mulai → Menu Utama → Pilih Menu → Proses Data → Tampilkan Hasil → Kembali ke Menu / Kelua
